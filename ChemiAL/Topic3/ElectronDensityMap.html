    3. What to notice

      Density along the bond

      The same map read along the straight line through both nuclei. Each peak is a nucleus. The dip between the peaks is the lowest density the two clouds share.

      Compare all four

      About the model. This is a teaching model, not a quantum calculation. Each cloud is built from smooth blobs holding a fixed number of electrons (for example 10 inner plus 8 outer electrons on Cl⁻). The map is a flat slice through both nuclei, so density is in electrons per square ångström; real maps are three-dimensional (e⁻/Å³) and come from calculation or X-ray data.

      Bond lengths: NaCl 2.82 Å (crystal), LiI 2.39 Å, HCl 1.27 Å, Cl₂ 1.99 Å. Electron counts around each nucleus are averages, because the electrons keep moving.
